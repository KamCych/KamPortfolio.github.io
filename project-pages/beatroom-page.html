    • Beat Room


    Based on traditional music equipment like the Roland SP404 sampler and the TR8 drum machine. This game captures the fun of physical hardware in a virtual form, without the expensive costs of equipment or DAWs. Perfect for beginners wanting to get started with production.






    Development

    Made in Godot, this ongoing project is teaching me many things there is to know about creating an immersive 3D experience, and constantly provides challenges when implementing the different features of a drum machine.

    Features:

  • 3D animation
  • Saving JSON data
  • 3D first-person camera controls
  • Sound FX
  • Object Oriented Programming
  • UI
  • Sound cooperation with visual effects
